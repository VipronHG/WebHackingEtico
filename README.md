# Proyecto de Hacking Ético – Keylogger en entorno controlado

Este repositorio contiene el material desarrollado para el **Trabajo Parcial del curso de Hacking Ético** de la Universidad Peruana de Ciencias Aplicadas (UPC).
El proyecto se centra principalmente en el desarrollo y análisis de un **keylogger** ejecutado exclusivamente dentro de un **entorno virtual, controlado y autorizado con fines académicos**. A partir de esta funcionalidad principal se añadieron diferentes características complementarias para ampliar el alcance de la práctica y estudiar su comportamiento desde una perspectiva ofensiva y defensiva.

## Objetivo del proyecto

El objetivo principal fue comprender el funcionamiento de un registrador de pulsaciones de teclado y analizar los indicadores que este tipo de software puede generar dentro de un sistema.

El keylogger implementado permite registrar:

- Pulsaciones de teclado.
- Teclas especiales.
- Marca de tiempo.
- Ventana activa asociada a las pulsaciones.

Como funcionalidades complementarias se trabajó también con:

- Arquitectura C2 para administración del agente.
- Heartbeat y registro de equipos.
- Panel de control mediante Discord.
- Captura de pantalla.
- Captura de audio de prueba.
- Ejecución remota de comandos en laboratorio.
- Transferencia controlada de archivos.
- Persistencia mediante tareas programadas.
- Cifrado reversible de archivos ficticios.
- Ofuscación del código.
- Firma del ejecutable con certificado de laboratorio.

## Entorno de pruebas

Todas las pruebas fueron realizadas en un **laboratorio virtualizado**, utilizando únicamente máquinas, archivos y credenciales creados específicamente para la práctica.

El proyecto no fue diseñado ni utilizado contra sistemas externos, equipos de terceros o información real.
